# วิธีอัปโปรแกรมขึ้นมาโชว์
- **ไฟล์โปรแกรม (.exe / .zip):** อย่าใส่ไว้ใน repo นี้ ให้ไปที่ GitHub → repo → Releases → Draft a new release → ลากไฟล์ใส่ → Publish แล้ว copy ลิงก์ไปใส่ใน `download`
- **โปรแกรมที่เป็นหน้าเว็บ (HTML):** ใส่ไว้ที่ `programs/<ชื่อโปรแกรม>/index.html` แล้วใส่ `demo: "programs/<ชื่อโปรแกรม>/"`
- **รูปหน้าจอ:** ใส่ไว้ที่ `programs/<ชื่อโปรแกรม>/screenshot.png` (ตรวจก่อนทุกครั้งว่าในภาพไม่มี Token หรือรหัสผ่าน)
