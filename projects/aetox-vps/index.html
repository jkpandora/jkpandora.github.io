บันทึกปัญหาและวิธีแก้

14 พ.ย. 2026 · แผนก 15 watchdog จาก FAIL เป็น PASS · แผนก 20 qa-100 จาก FAIL เป็น NEED_ACTION

#1 รอบตรวจของ watchdog ไม่ตรงกับ KPI (MTTD ≤ 1 นาที)

cron ตั้งไว้ */5 → เปลี่ยนเป็น * * * * *

#2 Telegram ตอบ HTTP 400 “chat not found”

chat id ที่ใช้เป็นแชทส่วนตัว ไม่ใช่ supergroup (ต้องขึ้นต้นด้วย -100) → หา id ที่ถูกด้วย getUpdates แล้วแก้ใน .env

บทเรียน: อย่าเชื่อ HTTP 400 จาก log เก่า ใส่เส้นแบ่งใน log แล้วทดสอบใหม่

#3 ทีม AI เปลี่ยนค่าที่แก้แล้วกลับเป็นแบบเดิม

ต้นเหตุคือ mission.txt ยังมีคำสั่งเก่า → แก้ mission.txt (เก็บสำรองไว้เป็น .bak) แล้วให้ n8n คอยเฝ้าทุก 5 นาที

⭐ ต้องแก้ที่ต้นทางคำสั่ง ไม่ใช่แค่ปลายทาง

#4 ไม่มี Git และไม่มีหลักฐาน Backup/Restore

รัน git init ใส่ .env และ log ไว้ใน .gitignore แล้ว commit ไป 3 ครั้ง

#5 กู้คืน SurrealDB ไม่ผ่าน (แก้ไป 5 ชั้น)
#Errorวิธีแก้
1field 'in' already existsใส่ OVERWRITE ให้ DEFINE FIELD
2embedding[*] already existsใส่ OVERWRITE ให้ทุกคำสั่ง DEFINE
3docker run requires 1 argumentย้ายคำสั่งไปไว้ในไฟล์ restore_test.sh
4Parse error บรรทัด 393กรองบรรทัด log INFO ออกจากไฟล์ backup
5PASS หลอกถ้าไม่มีไฟล์หรือไฟล์ว่าง ให้ออกผลเป็น FAIL
✅restore_test=PASS (32K)

⭐ ต้องเช็กว่าไฟล์ backup มีข้อมูลจริงและกู้คืนได้จริง

#6 n8n เชื่อมต่อ SSH เข้า VPS ไม่ได้

VPS ปิดการล็อกอินด้วยรหัสผ่าน → สร้าง key ให้ n8n โดยเฉพาะ · IP gateway ของ Docker ใช้ไม่ได้ → เปลี่ยนไปใช้ IP ภายในของ VPS · เพิ่ม IP ลงใน from= และเปลี่ยน Credential เป็นแบบ Private Key

#7 AI อ่านภาษาไทยไม่ได้ (ascii codec)

เติม LANG=C.UTF-8 PYTHONIOENCODING=utf-8 หน้าคำสั่ง python3

#8 แจ้งเตือนหลอกจาก log เก่า

เก็บ log เก่าเป็น watchdog.log.old-YYYY-MM-DD แล้วเริ่มไฟล์ใหม่

Lessons Learned

1. แก้ที่ต้นทางคำสั่ง

ถ้าไม่แก้ไฟล์คำสั่งที่ agent ใช้ด้วย ทีมจะเปลี่ยนค่ากลับเป็นแบบเดิม

2. PASS ต้องมีหลักฐาน

เช็กว่าไฟล์มีข้อมูลจริง และมีเวลาที่อัปเดตจริง

3. log เก่าหลอกตา

ใส่เส้นแบ่งก่อนทดสอบทุกครั้ง

4. AI ต้องอยู่ใน whitelist

ห้ามให้ AI รันคำสั่งอะไรก็ได้ด้วยสิทธิ์ root

5. ระวังภาพหน้าจอ

ถ้า Token หลุดไปแล้ว ต้อง revoke ทันที

6. คำสั่งยาวให้เขียนเป็นสคริปต์

วางหลายบรรทัดลง SSH ตรงๆ บรรทัดอาจซ้อนกันจนคำสั่งเสีย
